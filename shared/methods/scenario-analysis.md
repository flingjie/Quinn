# 情景推演（Scenario Analysis）

## 解决的问题
面对高度不确定的未来，组织"如果……会怎样"的多种可能，而不是押注单一预测。

## 简短解释
用少数几个关键不确定轴，构造几个内在一致的情景；再比较不同情景下的结果，找出跨情景都成立的稳健结论与早期信号。

## 使用步骤
1. **找关键不确定因素**：选出 2–3 个对结果影响最大、又最不确定的变量。
2. **组合成情景**：用这些变量构造 2–4 个内在一致的情景（不是随意罗列）。
3. **描述每个情景的机制与结果**：各情景下会发生什么、谁受益谁受损。
4. **找稳健结论与信号**：哪些结论在所有情景都成立；哪些早期信号能判断正走向哪个情景。

## 适用条件
2–5 年产业方向、战略选择、重大不确定下的判断。

## 局限
- 情景不是概率预测，不给"哪个更可能"的确定性。
- 情景数量不是质量；应基于真实分歧构造，不机械凑数。
