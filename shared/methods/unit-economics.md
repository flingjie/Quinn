# 单位经济（Unit Economics）

## 解决的问题
判断一个生意在"单个单位"层面是否赚钱，以及规模化后经济性如何变化。

## 简短解释
把收入与成本摊到一个可重复的单位（一次成功任务、一个用户、一单交易），算出单位毛利与回收周期。它回答的是"每做一单，是赚是亏、多久回本"，而不是总收入好不好看。

## 使用步骤
1. **定单位与分母**：选定"一个单位"是什么，并写清分母（每成功任务 / 每付费用户 / 每单）。
2. **列完整成本项目**：模型调用、算力、人力、获客、基础设施、支持、退款——不只列显眼的那个。
3. **区分 Token 单价与成功任务成本**：一次成功任务可能需要多次调用、重试、上下文重放、人工兜底，单价低不等于任务成本低。
4. **标周期与假设**：成本是月度还是年度口径，关键假设（调用量、成功率、单价）分别写清。

## 适用条件
AI 产业成本、SaaS、订阅、按结果收费等商业模式的经济性判断。

## 局限
- 单位经济不是估值；它不回答"值多少钱、能长多大"。
- 成本结构随规模与技术变化，早期数字是假设而非结论，要标注。
