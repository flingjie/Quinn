# 反馈与评分指南（feedback-guide）

版本：v1

## 1. 通用反馈原则

- 反馈约 200–400 字：已抓住的点 / 本轮变化或合理坚持 / 初判分与提示后分及证据 / 下一次一个建议。
- 不奖励长篇回答、术语数量或迎合 AI；不同结论按推理评分。
- 用户未选择教练偏好的选项不能扣分。
- 用户原话是证据；AI 措辞不能冒充用户能力。

## 2. 0–4 评分锚点（通用，辅助解释）

| 分数 | 含义 |
| --- | --- |
| 0 | 信息足够时，出现与本题目标有关的关键误判 |
| 1 | 提到相关变量，但未建立影响选择的关系 |
| 2 | 识别核心关系，并用于解释选择 |
| 3 | 正确使用关系，同时说明重要条件或未知项 |
| 4 | 在本题需要的范围内，检验关键边界并作出证据相称的判断 |

- 每题只按该题目标评分；不足以判断时为 null 并说明原因。
- 每题 `coach.md` 提供更贴近本题的锚点与短回答示例，优先使用。
- 分别展示初判分与提示后分；无后续回答则提示后分为 null。

## 3. 初判分 vs 提示后分

- 初判分观察独立表现；提示后分观察提示下的表现。
- 新增事实或改变目标时，明确两次回答的条件不同，不把分差当作进步量。
- 复测先冻结无提示初判再教学；之后的改进不倒算为无提示表现。

## 4. 挑战三种含义

| 类型 | 观察对象 | 不能声称 |
| --- | --- | --- |
| 检查原推理 | 原目标和事实下是否存在遗漏 | 用户一改答案就说明已掌握 |
| 新增事实 | 是否根据新证据合理更新 | 原判断必然错误 |
| 改变目标或约束 | 是否理解行动对条件的依赖 | 新选择证明原选择错误 |

反馈必须区分上述三类，措辞不得把「改答案」宣称成「已掌握」，不得把「条件变了」宣称成「原判断错误」。

## 5. 能力等级（L0–L4）

| 等级 | 证据标准 |
| --- | --- |
| L0 直觉判断 | 表达选择，但很少说明成立条件 |
| L1 提示下识别 | 经提示后能识别重要变量并解释 |
| L2 独立分析 | 新题初判中主动使用重要变量 |
| L3 假设驱动 | 主动说明关键边界、证据缺口和验证办法 |
| L4 结构迁移 | 多个不同情境中无提示使用相同底层关系 |

- 等级仅针对具体能力（如「识别规模化交付成本」），按原文证据判断，不由平均分计算。
- L4 需要多个陌生情境的独立证据；一次变式成功写「出现一次迁移迹象」，不宣布稳定掌握。

## 6. 复盘格式

用户请求复盘时，对照初判与后续证据：

1. 按具体目标汇总独立证据与提示后证据。
2. 给暂定能力描述（例：「识别规模化交付成本暂定 L2，依据两次独立初判；其他能力证据不足」）。
3. 给一个后续重点。
4. 诚实区分：独立表现 / 提示后表现 / 证据不足。
