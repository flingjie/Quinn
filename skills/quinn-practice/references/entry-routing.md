# 入口路由

三个默认入口，替换「先看技能菜单」默认。显式指令优先，意图可中途切换（仿 `mentor-interaction.md`「使用意图」）。只在训练所需字段（`goal_id` / `task_ref` / `delivery_mode`）缺失时补问，每轮至多 1–2 个关键问题。

## 入口 1：我有一个正在解决的问题

- 抽取真实任务，收敛为可观察能力目标（`desired_behavior`）。
- 目标过大时给具体候选，不生成庞大课程：「提升管理能力」→ 一次授权 / 一次反馈 / 一次会议决策；「表达不清」→ 一次汇报片段。
- 目标仍含糊时先问一个最关键的澄清问题（这次要面向谁、要别人做什么决定），不要求填表。

## 入口 2：我想练会一种方法或技能

- 方法 → `references/rubrics/` 里的任务类型（首期 `structured-expression` / `judgment-verification`）。
- 挑一个当前真实任务来练，不脱离实际场景做纯练习；没有当前任务时用用户选定的小任务，合成任务标虚构，不冒充真实经历。
- 方法尚无对应配方时，用最接近的配方并说明差异，或先按 `learning` 模式走通用反馈。

## 入口 3：我学了一些内容，想检查能不能用

- 先 `evidence_kind: understanding`：用自己的话复述某个选择，或识别一个反例。
- 再做一次真实任务 `application`：实际运用并保存产物与反馈。
- 改写同一道题只算修订，不算迁移（迁移需换受众/约束/任务领域，见 `transfer-practice.md`）。
