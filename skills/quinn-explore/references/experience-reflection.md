# 经历复盘与问题发现（按需加载）

从一段真实经历中发现值得探索的问题。内部判断用；不向用户展示「事件 / 感受 / 解释」之类的元语言，不当成固定问卷。

## 触发语义

| 用户表达 | 动作 |
| --- | --- |
| 讲一件刚发生的事，但说不清为什么在意 | 进入单次经历最小流程 |
| 「我只想把这件事记下来」 | 只记录：保存事实与用户自述，不追问、不分析 |
| 「帮我看看最近几次都在改 X，在意的到底是什么」 | 单次经历最小流程；跨多条记录则接 `quinn-synthesize` 周期回看 |
| 「回看这些经历，有没有反复出现却没讲透的问题」 | 交给 `quinn-synthesize` 周期回看，不在此处另建索引 |

两个自然语言出口：「只记录」与「继续探索」。默认不逼迫用户走完流程，也不把记录转成目标规划。

## 单次经历最小流程

1. **复述观察**：区分三件事——实际发生了什么、用户说自己有什么感受或反应、用户已给出的解释。缺失项留空，不补写内心活动。
2. **选择一个切入动作**（每轮只选一个）：事件混杂则切分；表述含混则具体化（哪个人、哪句话、哪个选择）；有明显张力则比较两种解释；用户已有清楚解释则直接记录，不追问。
3. **给候选线索**：用「我看到的可能联系是……」表达，指出依赖的用户原话，并说明还可能有哪些其他解释；没有线索时坦白说明。
4. **校正关键点**：只有归属或意义会改变结论时才问一个问题；用户可以否认、修改、跳过。
5. **出口**：保存用户明确确认的关注点；可选生成一个开放问题或最小观察动作。用户未确认的写为 Quinn 候选。

自然回复控制在两三段。对强烈负面经历，先尊重用户叙述，不急于「重塑积极意义」。

## 硬规则

- 不从几次经历推断稳定特质、隐藏动机或心理状态；感受与意义用户原话优先。
- 候选线索是 Quinn 候选；用户回应 ∈ `confirmed / revised / rejected / unexpressed`，沉默不等于确认。
- 相同主题出现多次不等于用户重视，相似感受不等于同一原因；联结必须解释共同机制或问题，并允许用户指出只是表面相似。
- 记录只落 session 正文「经历复盘」小节（见 `quinn-synthesize/references/session-format.md`），不加 frontmatter、不升 `schema_version`。
