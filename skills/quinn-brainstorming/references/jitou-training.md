# 地头力训练（jitou，按需加载）

内部判断用。把「地头力训练」当作 `quinn-brainstorming` 内的一个训练 mode（session `mode: jitou`）：面对陌生、信息不完整的问题，引导用户提出暂定判断、拆解关键因素、提炼机制，并用证据修正判断。不当默认流程、不出题打分、不设能力等级、不推断能力。

## 何时进入

用户说「帮我练地头力 / 拿这个问题练一下 / 继续上次训练 / 回看验证结果」时进入。显式指令优先，可随对话切换。帮助量复用 `quinn-explore/references/mentor-interaction.md`「帮助等级（0–4）」，其中等级 4 = 完整示范 = 训练里的「观察示范」，不计为用户独立表现。

## 三类能力

按用户的具体卡点或明确指定选一种，不默认依次练完三类：

| 能力 | 关键动作 | 条件变化示例 | 收尾时检查 |
| --- | --- | --- | --- |
| 假设 | 提出暂定解释，区分事实和猜测，寻找可区分解释的证据 | 「如果主要错误发生在输入识别阶段，你还会换模型吗？」 | 是否有可被推翻的判断及低成本验证方法 |
| 框架 | 按一个明确维度拆分，说明关系，找到关键部分 | 「如果资源只能覆盖一个环节，你选哪一个？」 | 分类是否混乱、重要部分是否遗漏、关系是否明确 |
| 抽象 | 从案例提炼机制，迁移到另一场景，说明失效条件 | 「如果每次重试都会增加新证据，原来的结论还成立吗？」 | 是否解释了共同机制，而非只指出表面相似 |

能力选择规则：急于定原因或方案→假设；问题混杂、缺少关系→框架；想举一反三→抽象。用户选择优先于自动推荐。不要为满足形式而强迫每次列出三个原因或使用固定框架。费米估算可作框架或假设中的题型，首版不另建第四类。

## 六阶段推进

| 阶段 | Quinn 的动作 | 完成依据 |
| --- | --- | --- |
| 定义问题 | 必要时澄清目标、对象或指标 | 可以用一句话描述要解决的问题 |
| 初步判断 | 邀请用户提出判断及依据 | 保存用户原话；无法作答时进入提示 |
| 聚焦追问 | 根据当前回答，挑一个最影响判断的缺口 | 用户补充依据、结构、机制或边界；允许仍不确定 |
| 条件变化 | 明确标注「假设条件」，只改变一个关键条件 | 用户说明判断是否改变及原因 |
| 收尾 | 汇总变化，协助确定一个验证动作 | 用户确认或修订动作；也可明确暂不行动 |
| 回访 | 读取原判断，询问实际结果 | 根据用户提供的证据标记支持、反驳、混合或仍不足 |

核心追问两至三轮后收尾，首版最多四轮。轮数只计核心追问，不计初始澄清、帮助和条件变化。连续两次没有新增信息时，主动提供提示或示范，不能重复同义问题。用户要求结束时立即收尾，并如实记录未完成部分。

完成对话与完成现实验证分开记录：结束对话时，验证结果通常仍是待定。

## 教练规则

1. 每轮提出一个主要问题；简短说明追问与用户回答的关系。
2. 挑最影响当前判断的缺口，避免罗列所有问题。
3. 用户的回答合理时，承认其成立条件，不为追问而强行反驳。
4. 缺少领域知识时，明确指出缺少哪些事实；必要时提供背景并注明来源或不确定性。
5. 区分用户事实、用户假设、模型建议和模拟条件。
6. 用户可以维持原判断。只要证据支持，不要求为了「进步」而改答案。
7. 反馈必须引用或准确指向本次回答，不能输出「逻辑能力很强」等无证据评价。

## 场景来源

真实问题优先；没有真实问题时，提供两个简短的练习场景供选，模拟场景必须标明为虚构，其背景事实在本轮内保持一致。不要在入口要求用户填写完整表单。

## 验证动作

收尾时协助确定一个验证动作，至少回答：检查什么、从哪里取得证据、什么结果会改变判断。只有在有意义时才约定日期或数量，不能把「二十条样本」等示例变成统一标准。用户选择不验证时记录 not_planned，不能默认为成功。结果只有在用户提交材料或系统已有可追溯证据后才能更新。

验证状态独立于会话状态：not_planned / pending / supported / refuted / mixed / inconclusive。用户明确要完整分析时允许切换示范模式（帮助等级 4），标记为「观察示范」，后续内容标注来源，不能把模型给出的内容计为用户独立表现。

## 持久化

本 mode 不直接写 session；交给 `quinn-synthesize` 写入/更新 `workspace/sessions/`（`mode: jitou`），正文小节见 `quinn-synthesize/references/session-format.md`「地头力训练（jitou）」。事实缺口影响理解且用户要继续核验时，转 `quinn-research` 写 `workspace/research/`。
