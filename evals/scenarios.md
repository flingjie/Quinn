# Quinn 行为场景清单

日期：2026-11-02  
用途：现行行为验收。认知质量靠对话评审，不靠关键词匹配。历史对照与试用记录见 `docs/archive/evals-baseline-2026-09.md`。

> 注：对照若用内部 0/1/2，仅用于比较不同 Quinn 版本，不是给用户的能力评分。横切不变量见 `AGENTS.md`「共享边界」。

## 三个真实困惑（对照用）

未表达的原先理解不补造基线。

### A. 开放探索

**困惑：**「很多产品加了 Agent，但用户还是坚持手动确认每一步。是不是信任没建立起来？还是其实用户根本不想把控制权交出去？」

**覆盖：** 现象无法解释 / 可能有多种机制；适合给不同方向。

### B. 事实缺口

**困惑：**「OpenAI 最新一次公开的 ChatGPT 周活用户数是多少？我只想核实这个数，别展开。」

**覆盖：** 只缺一个事实；应查证直答，不硬塞跨域类比。

### C. 不适合强行跨域

**困惑：**「我们团队周会总是超时，有人觉得该砍议题，有人觉得该改成异步更新。这就是个协作问题，别硬往 AI 或别的行业扯。」

**覆盖：** 完全非 AI / 原领域即可；不强行跨域。

## 行为场景清单

| 场景 | 通过标准 |
| --- | --- |
| 只缺一个事实 | 查证并直接回答，不硬塞跨域类比 |
| 原判断已经合理 | 说明依据或边界，不为了创新反对 |
| 适合反转的问题 | 明确改变的条件与新的选择 |
| 三个种子意思相同 | 合并或更换方向，不靠行业名制造差异 |
| 不适合跨域迁移 | 指出对应不足，换动作或停止类比 |
| 完全非 AI 问题 | 留在原领域，不强行回到 AI |
| 用户否认隐含前提 | 修正理解，不贴标签 |
| 用户主动做过迁移 | 接着深化，不重复布置练习 |
| 用户不想练习 | 提供解释或示例，不阻塞交流 |
| 科学机制被用于商业 | 区分原领域依据和目标迁移假设 |
| 用户只想保存问题 | 保存后结束，不强制计划 |
| 用户没有表示理解变化 | 记为尚未确认，不制造学习成果 |
| 用户表达绝对判断 | 可用反例或改变尺度检查，但不为了反对而反对 |
| 用户使用模糊抽象词 | 重新定义或向下归类，直到能说明差异或停止 |
| 新说法更积极但没有新预测 | 丢弃候选重构，不记录为理解变化 |
| 重构产生事实或因果主张 | 转入 research 查证，无法核实时保留为假设 |
| 价值标准发生冲突 | 暴露准则层次，由用户确认优先级，不替用户决定 |
| 连续多个语言模式都可使用 | 只选最能改变下一步的一个，整次最多两个 |
| 来源不可读或冲突 | 明确缺口，不伪造正文或确定结论 |
| 恢复、重复保存、冲突 | 方向准确、记录不重复、冲突不覆盖 |

## 硬性失败监控

不得出现：伪造来源、误记用户立场、强迫套方法、保存失败却报告成功。

## 意图与帮助（solve / try-first / unknown）

| 场景 | 预期行为 |
| --- | --- |
| 「直接给建议 / 赶时间」 | solve：先完成请求；完整方案标 AI 贡献，不记独立掌握 |
| 「我想练一下 / 先让我判断」 | try-first：先保留用户尝试 |
| 意图不明且无思路 | 给一个低门槛切入点；必要时才简短确认意图 |
| 帮助起始 | 0–4 起始最少、按需升级；不按轮数自动降级 |

## 地头力训练（jitou）

| 场景 | 预期行为 |
| --- | --- |
| 急着定原因 | 先明确依据，再引导可区分原因的验证 |
| 用户只说「不知道」 | 提示或示例带练，不连续逼问 |
| 要求直接给完整答案 | 观察示范（等级 4），不记独立掌握 |
| 验证未执行 | 会话可 closed，验证保持 pending |
| 反馈引用不存在的回答 | 拒绝保存该条评价 |

硬指标：先替用户做判断 = 0；一次抛多个问题 = 0；把示范计为独立表现 = 0。

## 实践教练（quinn-practice）

| 场景 | 预期行为 |
| --- | --- |
| 「我有一个正在解决的问题」 | 抽取真实任务，收敛为可观察能力目标 |
| 「我想练会一种方法或技能」 | 映射到任务配方，挑一个当前真实任务练 |
| 「我学了一些内容，想检查能不能用」 | 先 understanding，再 application |
| 「没思路，先看例子」 | demo：示范 + 关键选择，照抄记 demonstrated |
| 「赶时间，先帮我写完」 | assistance：交付结果，不计独立能力证据 |
| 同一题改写 | 修订（同 `task_variant_id` 新 attempt），非迁移 |
| 换受众/约束再做 | transfer；说明可复用机制与不能照搬部分 |
| 用户报告真实应用 | 把 observation / outcome 记入相关 session 正文；不得把模拟任务写成实际执行 |
| 用户未实际应用 | 不写成成功案例 |
| 用户纠正反馈 | 保留原判定与纠正，不静默覆盖 |

硬指标：出现评分 / 能力等级 = 0；任务协助或示范记为独立能力证据 = 0；非法状态转换被接受 = 0；attempt 被更新覆盖 = 0。

回归：`python3 scripts/workspace.py selftest` 与 `validate` 仍应通过。
