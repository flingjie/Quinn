# 案例模板与验收（case-template）

每题一个目录 `cases/case_XXX/`，含 `brief.md` 与 `coach.md`。本轮无需 `outcome.md`。

## 1. brief.md（只含用户可见题面）

必须包含：教学模拟/真实改编标记、决策目标、资源约束、已知事实与数字、关键未知项、行动问题。

```markdown
# [中性标题：只描述场景，不出现学习目标/维度/关联原题]

题目类型：教学模拟 / 真实材料改编（附来源）

## 决策目标
[一句话：你要做什么决定]

## 背景
[情境，不暗示答案]

## 资源约束
[主要约束，如时间、预算、人力]

## 已知数据
- [带单位的数字，口径一致]

## 未知信息
- [明确列出题目未提供、需要用户判断或验证的信息]

## 待决策问题
[行动问题]
```

提问原文：

- 基础题：「你会怎么选？主要依据是什么？什么条件会改变你的选择？」
- 复测题只问：「你会怎么选？请说明依据。」不展示学习目标、关联原题、能力标签或检查框架。

默认把目标和主要约束放在题面。若刻意缺少目标，学习目标必须明确为「识别目标不清并澄清」，不能事后用新增目标判初判错误。

## 2. coach.md（教练侧，不给唯一结论）

必须包含：

- 一个学习目标及其可观察证据。
- 题目中的事实、教学假设与未知信息。
- 至少两条可接受的推理路径；条件不同可作不同选择。
- 本题 0–4 分锚点，以及少量短回答示例。
- 常见遗漏和一条少提示的挑战示例。
- 什么情况应停止挑战、直接反馈。

```markdown
# [标题] · 教练笔记

tags：[六维内容标签，可交叉]
role：practice / transfer
transfer_of：case_XXX（变式时；基础题为 null）

## 学习目标
[一个可观察的判断动作]

### 可观察证据
[初判中出现什么迹象说明达成目标]

## 事实、教学假设与未知
- 事实：…
- 教学假设：…
- 未知：…

## 可接受推理（至少两条）
1. …（条件 → 选择）
2. …

## 0–4 评分锚点（本题）
0 = …；1 = …；2 = …；3 = …；4 = …

## 短回答示例
- 0 分示例：…
- 2 分示例：…
- 4 分示例：…

## 常见遗漏与挑战示例
- 常见遗漏：…
- 挑战示例：「你提到…」→ 一个少提示问题

## 何时停止挑战
[什么情况下直接反馈、不再挑战]
```

## 3. 题目验收

- 信息足以支持有条件的判断；单位一致；存在真实取舍；无需大量行业知识；题面不暗示目标答案。
- 变式必须更换表面情境，同时保留关键关系，不能只是替换公司名称与金额。
- 优先采用人工精选、核实过的真实材料改编；没有合适材料时用明确标记的教学模拟；不编造来源、用户访谈或真实经营结局。
