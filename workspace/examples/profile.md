# Profile 示例（格式参照）

> 真实文件位于 `workspace/profile.md`（gitignore，个人数据）。无文件则视为空偏好。只记录用户**明确说过**的偏好及来源；禁止自动推断能力、性格或稳定认知习惯。

```markdown
# Quinn 显式偏好

## 兴趣范围
- Agent 产品中的信任与控制权（来源：2026-09-12 用户说明）
- 团队协作节奏（来源：用户纠正「不要总往 AI 上靠」）

## 不要默认做的事
- 不要强行跨到不相关行业（来源：用户明确要求）

## 来源日志
- 2026-09-12：用户说「我对 Agent 信任和手动确认很感兴趣」
```

兴奋、继续追问可以记在对应 session 里，不作为“理解提升”的证据，也不自动提升为长期画像。
