# 复盘格式（review-template）

版本：v1

用户请求复盘时，按以下结构生成，只读已完成记录。

## 1. 阶段复盘回答四问

1. 哪次挑战指出了原回答里可验证的遗漏？
2. 用户是否改变了因果解释、数量估算或行动条件，而非只是复述 AI？
3. 后续初判是否主动使用该变量？
4. 还在哪些情况下依赖提示？

## 2. 暂定能力等级

- 先对已观察到的能力给暂定等级（L0–L4，见 rubric.md），不强行给全局综合等级。
- 例：「成本判断暂定 L2，依据两次独立初判；其他维度证据不足。」
- 记录不足、不同行为冲突或仍依赖提示时，明确保留不确定性。

## 3. 后续重点

只给一个后续训练重点。

## 4. 可选追问

问一句：「这次最有帮助或最没用的地方是什么？」（不增加满意度问卷。）

## 5. 成效判断（非打分，逐条看证据）

不计算少量样本下的精确迁移率。若：

- 挑战持续有效、变式出现主动应用且使用负担可接受 → 继续补题。
- 只会复述 → 减少提示并检查变式设计。
- 挑战泛化 → 改案例与挑战规则。
- 分数争议大 → 先修评分解释。
- 长期只有案例知识价值而没有判断改善 → 重新评估训练定位，不凭一两次失败宣布方向无效。
