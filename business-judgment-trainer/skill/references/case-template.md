# 案例模板与人工验收清单（case-template）

每题一个目录：`cases/case_XXX/`，含 `brief.md`、`coach.md`，可选 `outcome.md`。

## 1. brief.md 模板（只含用户可见题目）

```markdown
# [标题]

题目类型：教学模拟 / 真实材料改编（附来源）

## 背景
[一至三段，交代情境，不暗示答案]

## 已知数据
- [带单位的数字，口径一致]

## 未知信息
- [明确列出题目未提供、需要用户判断或提出验证的信息]

## 待决策问题
[一句话的决策问题，例如「你会直接推广、小规模试卖，还是放弃？」]
```

要求：

- 不含主维度、结构标签或训练目标；不暗示答案。
- 数字单位一致（如统一「元/月/客户」）。
- 区分「已知数据」与「未知信息」。

## 2. coach.md 模板（教练侧，不给唯一结论）

```markdown
# [标题] · 教练笔记

主维度：成本 / 商业逻辑 / 风险 / 利润
角色：practice（基础） / transfer（变式复测）
transfer_of：case_XXX（变式时填写；基础题为 null）

## 关键关系
[本题最核心的、可能改变选择的一条关系，例如「交付人工时间随客户数线性增长」]

## 参考推理
[列出可接受的不同推理路径与成立条件，含口径一致的数量估算；不是唯一答案]

## 来源与教学假设
- 来源：教学模拟（虚构）/ 真实材料改编（附来源）
- 教学假设：[明确标注哪些是事实、哪些是教学假设、哪些是未知]
```

要求：

- 不给唯一投资结论，列出成立条件和可接受的不同推理。
- 允许「有依据地坚持」与「改变观点」都是好表现。

## 3. outcome.md 模板（可选，真实结局）

```markdown
# [标题] · 真实结局

状态：已核实 / 未知
来源：[URL 或出处]

## 结局
[经营结果，仅当实际核实后填写]
```

- 外部来源只有实际核实后才标「已核实」；无法核实的信息保留为未知，不捏造出处和经营结果。
- 只在反馈完成后才允许读取本文件。

## 4. 人工验收清单（每题发布前检查）

- [ ] 有真实取舍（不只有一个显然正确的选择）。
- [ ] 信息足以粗判。
- [ ] 数字单位一致。
- [ ] 只有一个主目标（主维度）。
- [ ] 事实与假设区分清楚。
- [ ] 没有在题面暗示答案。
- [ ] 变式题：表面情境不同但关键关系一致；未额外依赖大量行业知识；不泄露原题提示。
