# 评分锚点与能力等级（rubric）

版本：v1

## 1. 四个训练维度

| 维度 | 核心观察 | 题目示例 |
| --- | --- | --- |
| 商业逻辑 | 谁付钱、为何付钱、替代方案是什么 | 有人使用的功能是否值得收费 |
| 成本 | 哪项成本随客户或交付规模变化 | 人工服务是否吃掉软件利润 |
| 风险 | 哪个假设会推翻结论，如何验证 | 客户说喜欢是否意味着愿意付费 |
| 利润 | 收入与成本口径一致，能判断盈亏条件 | 月收入增长是否带来实际盈利 |

- 每题只指定一个主维度；其他维度可自然出现，不全部评分。
- 不要求用户每次完整覆盖四项。

## 2. 主维度评分锚点

| 分数 | 可观察表现 |
| --- | --- |
| 0 | 在题目信息足够的前提下，未涉及目标变量或存在关键错误 |
| 1 | 提到了变量，但没有解释它如何影响选择 |
| 2 | 建立基本因果关系，或完成核心数量估算 |
| 3 | 说明关键假设或边界，并据此支持选择 |
| 4 | 检查主要替代解释或敏感条件，给出与证据相称的判断 |

使用说明：

- 这些是反馈锚点，不是经过验证的能力量表。
- 每个分数需引用原文；允许多种合理结论。
- 题目缺数据或答案太短无法评估时，使用 `null` 并说明原因，不能简单判 0 分。
- 成本题不因没有写「付费者」扣分；商业逻辑题不因没有利润区间扣分。
- 挑战后是否更新单独描述，不纳入所有维度的共同最高分要求。

## 3. 能力等级（暂定）

| 等级 | 证据标准 |
| --- | --- |
| L0 直觉判断 | 表达选择，但很少说明成立条件 |
| L1 提示下识别 | 经提示后能识别重要变量并解释 |
| L2 独立分析 | 新题初判中主动使用重要变量 |
| L3 假设驱动 | 主动说明关键边界、证据缺口和验证办法 |
| L4 结构迁移 | 多个不同情境中无提示使用相同底层关系 |

使用说明：

- 先对已观察的能力给暂定等级，不强行给全局综合等级。例：「成本判断暂定 L2，依据两次独立初判；其他维度证据不足。」
- 不建立升级脚本，不取平均分换算等级。
- 记录不足、不同行为冲突或仍依赖提示时，明确保留不确定性。

## 4. 能力提升的把握规则

- 一次成功记为学习迹象，多次不同情境重复出现后再提高能力判断的把握。
- 同领域稳定后再尝试跨行业；行业知识不足与结构遗漏分开说明。
